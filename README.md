# 学生成绩管理系统

控制台版 + 网页版合一：一个 C++ 程序既提供控制台菜单，又内置 HTTP 服务，
网页前端（浏览器）与控制台操作**实时共享同一份数据**。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `sms.cpp` | 全部源码（控制台菜单 + HTTP 服务 + JSON 接口，单文件） |
| `index.html` | 网页前端（单页面，无需构建，由 `sms.exe` 直接提供） |
| `students.txt` | 数据文件（UTF-8，每行：`学号,姓名,语文,数学,英语`），每次增删改自动落盘 |
| `build.bat` | 一键重新编译（自动查找本机 Visual Studio C++ 工具链） |

## 编译

```bat
build.bat
```

依赖：Windows + Visual Studio（任意带 C++ 工具链的版本，
含 VS 2022/2026）。不装 VS 也可以用 Dev-C++、MinGW 等，把 `build.bat`
里的 `cl ...` 换成对应编译命令（需链接 `ws2_32`）。

## 运行（先运行后端）

```bat
sms.exe
```

启动后：

- 控制台进入菜单（操作提示里的命令行编号 0~6）；
- 同时 HTTP 服务启动，浏览器打开 **http://127.0.0.1:4399/** 即为网页版；
- 服务**只监听 127.0.0.1**，仅本机可访问，同一局域网的其他设备连不上。

其他启动方式：

```bat
sms.exe --server        :: 只跑 HTTP 服务，不进控制台菜单（适合后台运行）
sms.exe --port 9000     :: 换端口，网页访问 http://127.0.0.1:9000/
sms.exe --help          :: 帮助
```

两个端可以同时用：控制台录入的学生，网页刷新即可见，反之亦然。

## 拷贝到新电脑 / 没有 VS 的电脑

`--server` 模式下想停止：`Ctrl+C`，或在任务管理器结束 `sms.exe`，或执行
`taskkill /F /IM sms.exe`。查看端口占用：`netstat -ano | findstr 4399`。

`双击运行 = 控制台 + 网页服务`。这个模式下**关闭命令行窗口 = 停止网页服务**
（菜单里选 `0` 退出也一样），不会出现“关了窗口网页还能打开”的情况；
如果你遇到过，那是有另一个 `sms.exe` 实例还在后台跑，
用上面的 `taskkill` 结束即可。

拷到没装 Visual Studio 的新系统也能直接用：程序是静态链接的
（`/MT`，不依赖 VC++ 运行库），Windows 10/11 x64 即可运行，
把 `sms.exe`、`index.html`、`students.txt` 三个文件一起拷走即可。

## 控制台功能（0~6）

```
1、录入学生信息    学号/姓名/语文/数学/英语；学号查重，成绩限 0~100
2、显示学生信息    表格展示（中文按 2 列对齐）与学生人数
3、删除学生信息    按学号删除，需输入 y 确认
4、修改学生信息    按学号修改，直接回车表示该项保持不变
5、查找学生信息    按学号精确匹配或姓名包含关键字模糊查找
6、按总分排序      可选从高到低 / 从低到高，排序结果落盘
0、退出系统        保存数据后退出
```

输入校验：非法命令、非数字成绩、越界成绩都会要求重输；
输入按行读取，任何非法输入都不会死循环，也不影响后续操作。

## 网页版功能

表格展示（支持按语文/数学/英语/总分着色）、录入、修改（表单回填）、
删除（弹窗确认，可取消）、查找（学号/姓名关键字）、排序
（总分降序/升序/按学号）、刷新，以及每步操作的 toast 提示和
平均分/最高分统计。页面右上角操作提示 2.6 秒自动消失。

## 接口（前端与后端对接用）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 网页前端 `index.html` |
| GET | `/api/students` | 学生列表；参数 `sort=total_desc/total_asc/stuno`，`q=关键字` |
| POST | `/api/students` | 录入，JSON：`{"stuno","name","chinese","math","english"}` |
| PUT | `/api/students/<学号>` | 修改，JSON 字段同录入 |
| DELETE | `/api/students/<学号>` | 删除 |

非法请求会被拒绝并返回中文错误信息：学号重复 409、成绩越界/非数字/缺字段 400、
学生不存在 404、方法不支持 405。

示例：

```bat
curl http://127.0.0.1:4399/api/students
curl -X POST http://127.0.0.1:4399/api/students -H "Content-Type: application/json" -d "{\"stuno\":\"2024001\",\"name\":\"张三\",\"chinese\":90,\"math\":85,\"english\":88}"
curl -X DELETE http://127.0.0.1:4399/api/students/2024001
```

## 实现要点

- 单文件 C++17，仅依赖 Winsock2（`ws2_32.lib`），无需第三方库；
- 控制台主循环与 HTTP 服务线程并发运行，学生数据用互斥锁保护；
- 数据内存中为 `std::vector<Student>`，每次变更立即写入 `students.txt`；
- 内含迷你 JSON 生成/解析（含 `\uXXXX` 转义与 UTF-8 输出），中文经 UTF-8 原样往返；
- 网页端 `fetch` 调用同源接口（都走 http://127.0.0.1:4399），不需要跨域；
  服务端不返回任何 CORS 头，也不监听外网地址，因此网页必须通过上面的地址打开，
  直接双击 `index.html`（file:// 协议）会因跨域被浏览器拦截。
